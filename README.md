# UrbanSound8K Audio Classification

## Что было сделано

В рамках проекта я:

- подготовил данные из датасета UrbanSound8K;
- реализовал преобразование аудио в mel-спектрограммы;
- добавил аугментации для обучающей выборки;
- обучил сверточную нейросеть для классификации аудиособытий;
- провел оценку качества с помощью 10-fold cross-validation по официальным фолдам датасета.

## Датасет

Использовался датасет UrbanSound8K, который содержит 10 классов городских звуков:

- `air_conditioner`
- `car_horn`
- `children_playing`
- `dog_bark`
- `drilling`
- `engine_idling`
- `gun_shot`
- `jackhammer`
- `siren`
- `street_music`

## Подход

Основная идея была такой:

1. загрузить аудиофайлы и привести их к единому формату;
2. преобразовать аудио в mel-спектрограммы;
3. обучить CNN-модель на этих признаках;
4. оценить качество на всех 10 фолдах и усреднить результат.

В проекте использовались аугментации аудиоданных, чтобы сделать модель устойчивее к вариациям входных сигналов.

## Модель

В качестве модели использовалась сверточная нейросеть для работы с mel-спектрограммами как с изображениями.
Архитектура включает несколько сверточных блоков с нелинейностями, нормализацией и последующей классификацией по 10 классам.

## Валидация

Качество модели оценивалось с помощью 10-fold cross-validation по официальному разбиению UrbanSound8K.
Это позволило получить более надежную оценку качества, чем при одном фиксированном train/validation split.

## Результат

В проекте была реализована рабочая модель классификации аудиособытий, обученная на mel-спектрограммах с использованием аугментаций и 10-fold cross-validation.
